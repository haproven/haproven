Haprocard

GitHub se Website tak Automatic Project Showcase

One File → Auto Update

🎯 Problem

Website ke Projects section me naya project add karne ke liye baar-baar HTML / JSON edit karna padta hai — image, title, description, live link, technologies sab manually daalna padta hai.

💡 Solution

Ek simple API banegi jo GitHub repositories ko scan karegi. Jis repo me haprocard.md file hogi, woh project automatically website pe dikhega.

Developer ko website ka code kabhi touch nahi karna padega.

⚡ Core Idea

GitHub Repo + haprocard.md = Project Source of Truth

GitHub pe file update → API automatically naya data padhegi → Website auto update.

🔄 Kaise Kaam Karega

1
Developer naya GitHub repository banata hai
2
Repo ke root me haprocard.md file banata hai
3
File me project ki saari details likhta hai (title, image, live link etc.)
4
git push karta hai
5
API detect karti hai → Website pe project automatically aa jata hai

📄 Activation File

haprocard.md

Har active project ke root me yahi file honi chahiye.

  • File name fixed hai → haprocard.md
  • Location → Repository root only
  • Is file ke bina project hidden rahega

🔗 Main API

https://api.haproven.com/github/{username}

Example:

https://api.haproven.com/github/codersusheel

Ye API user ke saare public repos scan karegi aur sirf un projects ko return karegi jisme haprocard.md maujood hai.

📝 haprocard.md me Kya Likhenge

Basic Info

Title, Project ID, Category, Status, Author, Date

Content

Description, Technologies, Image URL

Links

Live Project URL, GitHub Repository

Extra (Future)

Featured, Strength Score, Tags
