# 📝 Simple Suggestion

Agar sirf **idea, feedback ya suggestion** dena hai, to apne naam se ek `.md` file bana sakte ho.

### Example

```text
suggestions/
├── README.md
├── susheel.md
├── kushagra.md
└── shivam.md
```

### `susheel.md`

```md
# 💡 Suggestion — Susheel

## Idea

Haproven website me ek community events section add karna chahiye.

## Why?

Isse users upcoming hackathons aur events easily dekh sakenge.

## GitHub

https://github.com/yourusername
```

---

# 💻 Code / Project Suggestion

Agar suggestion ke saath **code, demo, design, component ya complete project** dena hai, to apne naam se folder bana sakte ho.

### Example

```text
suggestions/
└── susheel/
    ├── README.md
    ├── index.html
    ├── style.css
    └── script.js
```

### Folder ke `README.md` me batao:

```md
# 🚀 Suggestion — Susheel

## What is this?

Haproven ke liye proposed community page.

## Why?

Community members ko projects showcase karne ke liye.

## Files

- `index.html` — Main page
- `style.css` — Styling
- `script.js` — Functionality

## GitHub

https://github.com/yourusername
```

# 🖼️ Want to Be in Haproven Frame?

Agar tum **Haproven Frame** me apna profile/photo add karwana chahte ho, to suggestion me apna GitHub profile link mention karo.

Example:

```md
## 🖼️ Haproven Frame

I would like my GitHub profile to be considered
for the Haproven Frame.

GitHub:
https://github.com/yourusername
```

### Important

Haproven Frame me profile add karna **automatic approval nahi hai**.

The Haproven team may review the contribution/profile before adding it.

# 🔐 Privacy & Security

Please **do not share private or sensitive information** here.

Never add:

* ❌ Passwords
* ❌ API keys
* ❌ Access tokens
* ❌ Private credentials
* ❌ Personal documents
* ❌ Private user data

Only share information that is safe to be publicly stored in a Git repository.

---

# 🤝 Before You Submit

Please make sure:

* ✅ Your suggestion is related to Haproven
* ✅ Your idea is clearly explained
* ✅ Code is organized properly
* ✅ No private information is included
* ✅ Your GitHub profile is correct if you want Frame consideration
